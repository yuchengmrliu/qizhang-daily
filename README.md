# 起漲日報

台股每日自動選股網站。每個交易日收盤後掃描全上市櫃個股,用**基本面估值**與**技術面起漲訊號**雙重條件挑出候選股,自動發佈成一個手機可看的網頁。

沒有伺服器要維護,沒有月費,不需要手動執行。

## 怎麼用

打開網址就好。每天下午 4 點自動更新。

- **今日精選**:當天同時通過基本面與技術面門檻的股票
- 點任一檔進到**個股詳細**:近六個月日 K 線、近三年本益比位階,以及九項條件逐項的通過理由
- 也可以直接搜尋任一檔股票,不限於入選的

## 篩選條件

先排除流動性不足(近 20 日均量低於 500 張)與無本益比資料(虧損)的個股,再看九項條件。

**基本面(5 項)**

1. 本益比低於自身近三年的第 40 百分位
2. 本益比不高於 25 倍
3. 股價淨值比低於自身近三年中位數
4. 殖利率不低於 2%
5. 近四季每股盈餘未較一年前衰退

**技術面(4 項)**

1. 股價站上 20 日均線
2. 20 日均線走揚
3. 成交量放大至近 5 日均量的 1.5 倍
4. 逼近或突破近 60 日高點

基本面過 4 項以上**且**技術面過 3 項以上才入選。星等為兩邊合計的通過項數。

所有門檻集中在 [`pipeline/config.py`](pipeline/config.py),改參數不必動程式邏輯。

## 資料來源

臺灣證券交易所與證券櫃檯買賣中心的公開端點,免金鑰、免費。估值序列保留三年,K 線保留六個月。

## 本機執行

```bash
pip install -r requirements.txt
python -m pipeline.backfill    # 一次性歷史回補,約一小時
python -m pipeline.run_daily   # 產出 site/
python -m http.server 8765 --directory site
```

測試:

```bash
python -m pytest tests -q
```

## 自動化

`.github/workflows/daily.yml` 於每個工作日台北時間 16:00 執行:抓當日資料 → 算指標 → 篩選 → 發佈到 GitHub Pages。歷史快取存放在 `data` 分支,每次以單一 commit 覆蓋,repo 不會隨日子膨脹。

抓不到當日資料時(假日或來源異常)會沿用前一個交易日的結果,並在頁面上標示資料日期,不會讓網站空白。
